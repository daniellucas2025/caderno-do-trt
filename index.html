🛠️ Guia Prático de Manutenção

Como Atualizar Matérias, Editais e Adicionar Novos TRTs

A plataforma foi desenhada de forma 100% modular. Você não precisa alterar linhas complexas de código: basta editar os cadernos HTML ou executar os arquivos .bat com um duplo clique!

✏️

1. Atualizar Matérias Teóricas

Os cadernos completos de cada matéria ficam salvos na pasta Cadernos-Completos/ do tribunal.

  • Abra a pasta do TRT (ex: TRT-04-RS/Cadernos-Completos/).
  • Abra o arquivo HTML da matéria (ex: Direito do Trabalho_COMPLETO.html) em qualquer editor de texto.
  • Faça as atualizações de leis, súmulas ou anotações e salve o arquivo (Ctrl+S).
Local: caderno-do-trt/TRT-XX-UF/Cadernos-Completos/
⚡

2. Recompilar a Plataforma

Após editar qualquer caderno, execute o script automatizado para injetar o novo conteúdo no aplicativo web.

  • Abra a pasta Scripts-Geradores/ do TRT.
  • Dê dois cliques em 1. GERAR_PLATAFORMA.bat.
  • O script recompilará o Plataforma/index.html em 2 segundos!
Arquivo: Scripts-Geradores/1. GERAR_PLATAFORMA.bat
☁️

3. Enviar ao GitHub Pages

Para que suas alterações apareçam no site oficial da internet:

  • Dê dois cliques em 2. PUBLICAR_SITE.bat (ou use 3. GERAR_E_PUBLICAR_TUDO.bat).
  • O script faz o commit e o push para o GitHub automaticamente.
  • Em cerca de 60 segundos o GitHub Pages atualiza o site no ar!
Arquivo: Scripts-Geradores/3. GERAR_E_PUBLICAR_TUDO.bat
➕

4. Adicionar um Novo TRT

Quer incluir outro tribunal que ainda não está na lista (ex: TRT-10, TRT-18, etc.)?

  • Dê dois cliques no arquivo NOVO_TRT.bat na raiz do repositório.
  • Informe o número da Região (ex: 18), a UF (ex: GO) e o Nome (ex: Goiás).
  • O gerador cria a pasta completa, copia as 10 matérias e gera a plataforma automaticamente!
Arquivo: caderno-do-trt/NOVO_TRT.bat
🔒

5. Segurança e Proteção de CPF

Diretriz absoluta de proteção de dados (LGPD):

  • Nunca envie arquivos .PDF ao repositório (eles contêm marcas d'água com seu CPF).
  • O .gitignore já bloqueia *.pdf automaticamente em todo o projeto.
  • Todo o estudo é compilado em HTML seguro e sem identificadores pessoais.
Blindagem: .gitignore configurado com *.pdf
🏛️

6. Atualizar o Portal Hub

Se adicionar novos TRTs e quiser atualizar a vitrine deste portal:

  • Execute o script gerar_portal_hub.py na raiz.
  • Ele atualizará o index.html principal com os novos cards e estatísticas.
Comando: python gerar_portal_hub.py
